## 1. 제품 정의

### 대상 사용자
대한민국 거주자로, ETF 중심 장기 적립식 투자를 하고 있거나 시작하려는 개인. 세금과 연금 제도를 스스로 계산하기 어려워하는 30~50대가 주 사용자.

### 해결하는 문제
기존 복리 계산기는 "30년 후 10억"이라고만 알려줍니다. 사용자가 실제로 알아야 하는 것은:

1. 그 10억이 **오늘 돈으로 얼마인지** (물가)
2. 세금과 ETF 보수를 떼면 **실제로 얼마 남는지**
3. 그 돈으로 **매달 얼마씩 쓸 수 있고 몇 살까지 버티는지**
4. 국민연금까지 합치면 **목표 생활비의 몇 %를 채우는지**
5. 시장이 예상대로 안 움직이면 **얼마나 위험한지**

### 핵심 지표 (Hero Metric)
> **은퇴 후 매달 쓸 수 있는 금액 — 오늘 구매력 기준, 세금·건보료 차감 후**

모든 화면 설계는 이 숫자를 가장 크고 먼저 보여주는 것을 목표로 합니다.

### 제품 원칙
1. **정직함이 정확함보다 우선.** 근사 계산은 근사라고 밝힌다.
2. **가정은 항상 보인다.** 결과 옆에 가정이 없으면 미완성이다.
3. **조언하지 않는다.** 계산 결과와 사실만 제시한다.
4. **데이터는 사용자의 것.** 브라우저를 떠나지 않는다.

## 2. 범위

### MVP 포함 (M1~M4)
- 축적기 월별 시뮬레이션 (계좌 포트폴리오, 세금, TER 반영)
- 명목/실질 이중 표기
- 경제적 자유 필요자산 (인출률 4종 + 소진형 비교)
- 은퇴 후 인출 시뮬레이션 (전략 4종, 연령 구간별 타임라인)
- 계좌 유형 4종 + 국내/해외 ETF 과세 구분
- 국민연금 소득 반영, 건강보험료 근사
- 결과 대시보드 + 자산 성장 그래프 + 가정 패널

### MVP 이후 (M5~M7)
- 3시나리오 비교 (보수/기준/낙관)
- 역산 솔버 (필요 월 납입액 / 필요 수익률 / 최단 은퇴 나이)
- Monte Carlo 시뮬레이션 + SORR 분석
- 시나리오 저장·URL 공유, CSV/이미지 내보내기

### 명시적으로 범위 밖 (Non-goals)
| 제외 항목 | 이유 |
|---|---|
| 실계좌 연동, 실시간 시세 | 프라이버시 원칙 위반, 백엔드 필요 |
| 개별 종목·ETF 추천 | 투자 권유 회피 |
| 환율 모델링 | MVP에서는 "원화 기준 수익률" 가정으로 단순화 (P3 검토) |
| 부동산·사업소득 | 일회성 현금흐름 이벤트로만 근사 |
| 정확한 건강보험료 부과체계 재현 | 재산·소득 상세 입력이 과도. 근사 + 한계 고지 |
| 종합소득세 전체 신고 시뮬레이션 | 계산기 범위를 넘음. 금융소득종합과세 임계 경고만 제공 |
| 다국어 / 해외 세제 | 한국 거주자 전용 제품 |

## 3. 시스템 개요

```
┌──────────────────────────────────────────────────────────────┐
│  UI (React)                                                  │
│  입력 폼 ── Zustand Store ── 결과 대시보드 / 차트 / 가정 패널  │
└───────────────┬──────────────────────────┬───────────────────┘
                │ CalculatorInput          │ CalculationResult
                ▼                          ▲
┌──────────────────────────────────────────────────────────────┐
│  계산 엔진 (src/calc) — 순수 함수, React 의존 없음             │
│                                                              │
│  runFullSimulation(input, taxRules)                          │
│    ├─ accumulate()   축적기: 월별 루프, 계좌별 자산·과세      │
│    ├─ withdraw()     인출기: 구간별 인출, 전략 4종            │
│    ├─ calcFire()     필요자산: 인출률별 비교                  │
│    ├─ solve()        역산: 이분법 솔버                        │
│    └─ monteCarlo()   MC: 시드 PRNG (→ Web Worker)            │
└───────────────┬──────────────────────────────────────────────┘
                │ TaxRuleSet (주입)
                ▼
┌──────────────────────────────────────────────────────────────┐
│  제도 데이터 (src/data/tax) — 버전드, 출처·기준일·확정여부     │
│  kr-2026.ts  |  kr-2027.ts  |  ...                           │
└──────────────────────────────────────────────────────────────┘
```

핵심 설계 결정: **계산 엔진은 세율을 모릅니다.** 세율은 데이터 레이어에서 주입되며, 이것이 세법 변경 대응의 유일한 지점입니다.

## 4. 계산 흐름 (전체 파이프라인)

```
사용자 입력
   │
   ├─(1) 수익률 정규화 ────────────────────────────────┐
   │     Total Return을 가격상승률 + 배당수익률로 분해  │
   │     TER 차감 → 월 실효 배율 산출                   │
   │                                                    ▼
   ├─(2) 계좌 배분 ──── 월 납입액을 우선순위·한도에 따라 계좌별로 분배
   │                    (오버플로 처리, 세액공제 환급금 재투자)
   │                          │
   ├─(3) 축적기 월별 루프 ────┘
   │     계좌별로: 납입 → 배당 발생 → (과세계좌면) 원천징수 → 재투자 → 가격상승
   │     연 단위 스냅샷 기록 (명목/실질, 원금/수익 분해)
   │                          │
   ├─(4) 은퇴 시점 자산 확정 ─┘  ← 계좌별 잔액 + 원금/수익 비율
   │
   ├─(5) 목표 생활비 계산 ──── 오늘 기준 월 생활비 → 은퇴 시점 명목 환산
   │
   ├─(6) 필요자산 계산 ─────── 인출률별 필요자산 + 소진형 현재가치
   │                          연금소득·건보료·세금 gross-up 반영
   │
   ├─(7) 인출기 시뮬레이션 ─── 연령 구간별로 인출 → 세금 → 실수령
   │                          전략 4종 각각 실행
   │
   └─(8) 결과 조립 ─────────── 핵심 지표 + 연도별 표 + 그래프 데이터 + 가정 목록
```

각 단계의 수식은 [`02-calculation-engine.md`](./02-calculation-engine.md) 에 있습니다.

## 5. 개발 순서

`plan/design-review-v2.md` §4 의 M1~M7을 따릅니다. 요약:

| 마일스톤 | 완료 기준 |
|---|---|
| M1 | 세금 0% 가정으로 축적기·FIRE 계산이 골든 테스트를 통과 |
| M2 | 계좌 4종 과세가 데이터 파일에서 주입되고, 오버플로 배분이 동작 |
| M3 | 은퇴 후 구간별 인출 시뮬레이션 + 연금·건보료 반영 |
| M4 | 입력 → 결과 대시보드 → 그래프가 브라우저에서 동작 (배포 가능) |
| M5 | 3시나리오 비교 + 역산 솔버 |
| M6 | Monte Carlo 10,000회 3초 내, SORR 지표 표시 |
| M7 | URL 공유, 내보내기, 접근성 감사 통과 |

**M4까지가 사용자에게 가치를 주는 최소 단위입니다.** M5~M7 없이도 배포할 수 있게 설계합니다.
