# 01. 기능 명세

대응 요구사항: R1(입력 모델), R10(결과 화면)

---

## 1. 화면 구성

싱글 페이지, 좌측(또는 상단) 입력 · 우측(또는 하단) 결과. 입력 변경 시 즉시 재계산.

```
┌─ 헤더 ────────────────────────────────────────────────┐
│ 경제적 자유 계산기        [시나리오: 기준 ▾] [공유] [?] │
└───────────────────────────────────────────────────────┘
┌─ 입력 (아코디언 5개 섹션) ─┐┌─ 결과 ──────────────────┐
│ ① 기본 정보               ││ [핵심 지표 카드 4개]      │
│ ② 수익률·물가 가정         ││ [목표 달성률 게이지]      │
│ ③ 계좌 포트폴리오          ││ [자산 성장 그래프]        │
│ ④ 은퇴 설정               ││ [인출률 비교 표]          │
│ ⑤ 고급 (일회성 이벤트 등)  ││ [은퇴 후 구간별 현금흐름]  │
│                          ││ [연도별 상세 표]          │
│                          ││ [가정 패널 / 계산식 보기]  │
└──────────────────────────┘└─────────────────────────┘
┌─ 면책 문구 (상시 표시) ────────────────────────────────┐
```

모바일에서는 입력 → 결과 순서의 단일 컬럼, 결과 요약이 상단에 sticky.

## 2. 입력 명세

표기: **필수** / 선택. 모든 기본값은 보수적으로 설정합니다.

### ① 기본 정보

| 필드 | 타입 | 기본값 | 범위 | 비고 |
|---|---|---|---|---|
| 현재 나이 | 정수 | 35 | 19~80 | **필수** |
| 은퇴(경제적 자유) 목표 나이 | 정수 | 55 | 현재나이+1 ~ 85 | **필수** |
| 자산 사용 종료 나이 | 정수 | 95 | 은퇴나이+1 ~ 110 | 기대수명이 아니라 "이 나이까지 버티면 된다"는 계획 기준 |
| 총급여 구간 | 선택 | 5,500만원 초과 | 2택 | 연금 세액공제율 결정용(16.5% / 13.2%) |
| ISA 유형 자격 | 선택 | 일반형 | 일반형/서민형 | 서민형은 비과세 한도 2배 |

### ② 수익률·물가 가정

| 필드 | 타입 | 기본값 | 범위 | 비고 |
|---|---|---|---|---|
| 수익률 입력 모드 | 선택 | Total Return | TR / 분리 | §3 참조 |
| 예상 연평균 총수익률 | % | 7.0 | -5 ~ 20 | 12% 초과 시 경고 배지 |
| 배당수익률 | % | 1.5 | 0 ~ 10 | TR 모드에서도 필요 (과세 계산용) |
| 가격상승률 | % | (파생) | — | 분리 모드에서만 직접 입력 |
| 예상 연평균 물가상승률 | % | 2.0 | 0 ~ 10 | 근거: 한국은행 물가안정목표 2.0% |
| ETF 연간 총보수(TER) | % | 0.15 | 0 ~ 2 | |
| 은퇴 후 예상 수익률 | % | 4.0 | -5 ~ 15 | 은퇴 후 자산배분 보수화 반영 |
| 배당 재투자 | 토글 | ON | | OFF면 배당은 현금 유출로 처리 |
| 납입 시점 | 선택 | 월초 | 월초/월말 | |

**경고 규칙**
- 총수익률 > 12%: "역사적 장기 평균을 크게 상회하는 가정입니다"
- 총수익률 − 물가상승률 > 8%: "실질 기대수익률이 매우 높습니다"
- 배당수익률 > 총수익률: 입력 오류(막음)
- 은퇴 후 수익률 > 축적기 수익률: "은퇴 후 수익률이 더 높은 가정입니다" (허용, 경고만)

### ③ 계좌 포트폴리오

원안의 "계좌 유형 선택"을 **다중 계좌 + 오버플로**로 확장 (검토판 §2.5).

| 필드 | 타입 | 기본값 | 비고 |
|---|---|---|---|
| 월 총 추가 투자금 | 원 | 1,000,000 | **필수**. 이 금액을 계좌들에 자동 배분 |
| 매년 투자금 증가율 | % | 3.0 | 0~15. 임금상승 반영. 0이면 정액 |
| 계좌별 초기 자산 | 원 × 5 | 전부 0 | 일반 / ISA / 연금저축 / IRP / DC·퇴직금 |
| 배분 우선순위 | 정렬 가능 목록 | 아래 기본값 | 드래그로 재정렬 |
| 배분 모드 | 선택 | 자동(우선순위) | 자동 / 수동(계좌별 금액 직접 입력) |
| 세액공제 환급금 재투자 | 토글 | ON | 다음 연도 납입에 가산 |

**기본 배분 우선순위** (세제 혜택 큰 순서)
1. 연금저축 — 세액공제 한도까지 (연 600만원)
2. IRP — 세액공제 합산 한도까지 (연 300만원 추가)
3. ISA — 연 4,000만원 한도까지
4. 연금저축/IRP 추가 납입 — 합산 1,800만원 한도까지
5. 일반계좌 — 나머지 전부

각 계좌 옆에 실제 배분된 월 금액과 한도 소진율을 실시간 표시합니다.

## 3. 수익률 입력 모드 (원안 19행 요구의 구현)

원안의 요구는 "Total Return 입력 시 배당수익률을 중복 가산하지 마라"입니다. 다만 **일반계좌의 배당 원천징수를 계산하려면 배당 비중을 알아야 하므로**, 배당수익률 입력 자체는 제거할 수 없습니다.

```
모드 A: Total Return (기본)
  입력: 총수익률 7.0%, 배당수익률 1.5%
  내부: 가격상승률 = 7.0 - 1.5 = 5.5%
  화면: "총수익률 7.0% = 가격상승 5.5% + 배당 1.5%  (배당을 중복 더하지 않습니다)"

모드 B: 분리 입력
  입력: 가격상승률 5.5%, 배당수익률 1.5%
  내부: 총수익률 = 5.5 + 1.5 = 7.0%
  화면: "총수익률 7.0%"
```

- 두 모드는 **동일한 내부 표현**(`priceReturn`, `dividendYield`)으로 수렴하며, 모드 전환 시 값이 보존됩니다.
- 화면에는 항상 분해 결과를 표시해 사용자가 중복 계산이 없음을 확인할 수 있게 합니다.
- 배당 재투자 OFF일 때: 배당은 재투자되지 않고 인출되므로 자산 성장은 가격상승률만 반영합니다.

## 4. 인출 전략 4종

검토판 §2.1에서 확정한 내용입니다. UI에서 선택하며, 정의를 항상 함께 표시합니다.

| 전략 | 정의 | 장점 | 단점 | 고갈 위험 |
|---|---|---|---|---|
| **① 고정 실질 인출** (기본) | 첫해 = 자산 × 인출률, 이후 매년 물가상승률만큼 증액 | 생활비 안정 | 시장 하락에 대응 못함 | 있음 |
| **② 고정 비율 인출** | 매년 그 해 잔여자산 × 인출률 | 절대 고갈 안 됨 | 생활비 변동 큼 | 없음 |
| **③ 계획 소진형** | 종료 나이에 잔액 0이 되도록 실질 연금 방식으로 인출액 산정 | 자산을 최대한 활용 | 종료 나이 이후 자산 없음 | 계획된 소진 |
| **④ 매년 재계산형 (VPW)** | 매년 잔여자산·잔여기간으로 인출액 재산정 | 시장 반응 + 고갈 방지 | 생활비 변동 | 매우 낮음 |

원안의 "① 자산 보존형"은 ②에, "② 자산 소진형"은 ③에 대응합니다.

## 5. 결과 명세

### 5.1 핵심 지표 카드 (최상단, 순서 고정)

| 순서 | 지표 | 표기 예 |
|---|---|---|
| 1 | **은퇴 후 월 사용 가능액 (오늘 구매력, 세후)** | `월 287만원` + 부기 `명목 512만원` |
| 2 | **목표 달성률** | `95.7%` (목표 월 300만원 대비) + 게이지 |
| 3 | **예상 은퇴자산** | `12억 3,456만원` (명목) / `6억 9,012만원` (오늘 가치) |
| 4 | **총납입원금 / 투자수익** | `4억 2,000만원 / 8억 1,456만원` + 비중 바 |

카드 1은 다른 카드보다 시각적으로 크게 배치합니다.

### 5.2 목표 달성률 정의

```
달성률 = (은퇴 후 실질 월 세후 인출가능액 + 실질 월 연금소득) ÷ 목표 월 실질 생활비
```
자산 기준 달성률(`예상 은퇴자산 ÷ 필요자산`)도 보조 지표로 함께 표시합니다.

### 5.3 자산 성장 그래프 (원안 7번)

- X축: 나이 (또는 연도 토글)
- Y축: 금액
- 시리즈: **누적 납입원금**(면적) / **투자수익**(면적, 누적 위에 쌓기) / **총자산**(선)
- 토글: 명목 ↔ 실질
- 은퇴 나이에 수직 기준선 + 라벨
- 은퇴 이후 구간도 같은 차트에 연장 표시(자산 감소 곡선) — 전체 생애를 한 화면에서 보게 함
- 3시나리오 모드에서는 보수/기준/낙관 밴드 표시

### 5.4 주요 시점 스냅샷 (원안 30행)

5년 / 10년 / 15년 / 20년 / 30년 / 은퇴 시점의 명목·실질 자산을 카드로 표시. 투자 기간보다 긴 시점은 숨김.

### 5.5 인출률 비교 표 (원안 2번)

| 방식 | 필요 총자산 (은퇴 시점 명목) | 필요 총자산 (오늘 가치) | 월 인출 가능액 (세전) | 월 실수령액 (세후·건보료 차감) | 오늘 구매력 환산 | 내 예상자산으로 달성? |
|---|---|---|---|---|---|---|
| 연 3.0% 인출 | | | | | | ✅ / ❌ (부족액 표시) |
| 연 3.5% 인출 | | | | | | |
| 연 4.0% 인출 | | | | | | |
| 사용자 지정 (n%) | | | | | | |
| 계획 소진형 (~95세) | | | | | | |

각 행에 사용된 정의를 툴팁으로 제공하고, 4% 룰의 한국 적용 한계를 각주로 고지합니다.

### 5.6 은퇴 후 구간별 현금흐름 (검토판 §2.4)

브리지 기간 문제를 드러내는 핵심 표입니다.

| 구간 | 나이 | 사용 가능 재원 | 월 필요액 (명목) | 월 자산 인출 | 월 연금소득 | 월 세금·건보료 | 월 실수령 | 구간 말 잔여자산 |
|---|---|---|---|---|---|---|---|---|
| 브리지 1 | 55세 미만 구간 | 일반계좌, ISA | | | 0 | | | |
| 브리지 2 | 55세 ~ 연금개시 | + 연금저축, IRP | | | 0 | | | |
| 연금 수령기 | 연금개시 ~ 종료 | 전체 + 국민연금 | | | | | | |

은퇴 나이가 55세 이상이면 브리지 1은 자동 생략됩니다.

### 5.7 연도별 상세 표

접힌 상태로 제공. 열: 나이 / 연도 / 연간 납입 / 배당 / 원천징수 세금 / 평가이익 / 연말 자산(명목) / 연말 자산(실질) / 누적 원금 / 누적 수익 / 계좌별 잔액.
CSV 내보내기 지원.

### 5.8 가정 패널 (원안 8번 = R11)

항상 접근 가능한 패널로, 계산에 사용된 모든 값을 나열합니다.

```
── 사용된 가정 ──────────────────────────────
연평균 총수익률          7.00%
  ├ 가격상승률           5.50%
  └ 배당수익률           1.50%
ETF 총보수(TER)         0.15%
보수 차감 후 수익률       6.84%          ← (1.07 × (1-0.0015)) - 1
물가상승률               2.00%   (근거: 한국은행 물가안정목표)
실질 기대수익률           4.75%          ← (1.0684 / 1.02) - 1
은퇴 후 기대수익률        4.00%
은퇴 후 실질 수익률       1.96%
안전인출률               3.50%
납입 시점                월초 (annuity-due)
월 수익률 변환           기하평균 (1+r)^(1/12)-1
── 적용 세제 (기준일 2026-08-08) ────────────
배당소득 원천징수         15.4%          [확정] 출처↗
국내상장 해외ETF 매매차익  15.4%          [확정] 출처↗
ISA 비과세 한도           200만원        [검증필요] 출처↗
연금소득세               3.3~5.5%        [확정] 출처↗
...
── 한계 ────────────────────────────────────
· 환율 변동은 반영하지 않습니다 (원화 기준 수익률 가정)
· 건강보험료는 근사값입니다
· 세법은 변경될 수 있습니다
```

각 항목 옆 `출처↗` 는 실제 URL로 연결됩니다. `[검증필요]`, `[개정안]` 은 색상 배지로 구분합니다.

### 5.9 계산식 보기 (원안 172행)

각 결과 항목에 "계산식 보기" 버튼. 클릭 시 실제 사용된 수식과 대입값을 표시합니다.

```
은퇴 시점 자산 (명목)
  월별 반복: balance ← (balance + 월납입액) × (1 + r_m)
  r_m = (1 + 0.0684)^(1/12) - 1 = 0.005525
  240개월 반복 → 1,234,560,000원

오늘 구매력 환산
  1,234,560,000 ÷ (1 + 0.02)^20 = 830,912,000원
```

## 9. 입력 검증 규칙 요약

| 규칙 | 처리 |
|---|---|
| 은퇴 나이 ≤ 현재 나이 | 차단 |
| 종료 나이 ≤ 은퇴 나이 | 차단 |
| 배당수익률 > 총수익률 | 차단 |
| 국민연금 개시 나이 < 은퇴 나이 | 허용 (은퇴 후 바로 수령 가능) |
